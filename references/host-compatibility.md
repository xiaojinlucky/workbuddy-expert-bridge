# 宿主兼容性

核心 Skill 只依赖 Agent Skills 文件、WorkBuddy 专家文件和有界文件读取。宿主专用发现路径放在本文件，不进入核心流程。

| 宿主能力 | 要求 | 缺失时的结果 |
| --- | --- | --- |
| Skill 发现 | 读取用户级或项目级 `.agents/skills/`，或允许配置等价 Skill 根目录 | 无法自动触发；需要安装到宿主声明的目录 |
| 本地文件 | 读取 WorkBuddy 配置、清单与 Markdown | 核心功能不可用 |
| Python 3.10+ | 运行确定性发现脚本 | 可按相同边界手工只读发现 |
| 隔离委派 | 独立执行专家团角色 | 降级为顺序角色回合 |
| 命令执行 | 运行测试或项目命令 | 只提供未执行的命令与限制说明 |
| 网络与连接器 | 仅在所选专家和当前任务确实需要时使用 | 标记能力缺口；不影响纯本地专家时继续 |

## 重要边界

- “模型支持”与“宿主支持”不是一回事。模型只有在宿主加载 Skill 并提供文件、命令或委派能力后才能执行。
- 本地用户级 Skill 不会自动出现在远程或云端工作机。远程执行时把 Skill 作为项目级文件提交，或在目标机器单独安装。
- 本地编程宿主的 Skill 机制不能证明普通网页或移动端聊天会读取电脑上的这个目录。
- 宿主即使能加载 Skill，也可能没有子 Agent、浏览器、图像或某个连接器；按能力映射降级。

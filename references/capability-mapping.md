# 宿主能力映射

## 状态

每项能力必须标为：

- `AVAILABLE`：当前宿主提供并已确认接口；
- `PARTIAL`：只能完成部分语义；
- `UNAVAILABLE`：没有该能力；
- `BLOCKED`：能力存在，但权限或状态阻止使用；
- `NOT_APPLICABLE`：当前任务不需要。

不要从宿主名称推断能力，也不要为匹配 WorkBuddy 工具名而发明接口。

## 语义映射

| 专家包意图 | 通用能力 | 缺失时的处理 |
| --- | --- | --- |
| 向成员发送任务或消息 | 隔离委派、子 Agent、独立会话 | 在当前 Agent 中顺序执行角色回合，并明确降级 |
| 创建、更新任务 | 计划或状态跟踪 | 用宿主现有计划能力；没有时使用简短阶段清单 |
| 读取项目或参考文件 | 有界文件读取与搜索 | 没有本地读取能力时停止 |
| 执行命令或测试 | 进程执行能力 | 输出可复制命令并标为未执行，不得声称通过 |
| 浏览网页或搜索 | 网络检索能力 | 使用本地证据，或说明哪些事实无法核实 |
| 调用 MCP、连接器或应用 | 已安装且可验证的外部能力 | 标为不可用；只有依赖决定结果时阻塞 |
| 生成或检查图片 | 图像生成或视觉检查 | 提供文字规格，明确未生成或未视觉验收 |
| 持久记忆 | 项目状态文件或宿主持久上下文 | 在当前任务维护最小状态，不假装永久记忆 |
| 展示或交付文件 | 宿主文件展示能力 | 返回绝对路径或宿主支持的附件方式 |

## 专家团执行

`delegated-team` 适用于宿主具备隔离执行能力、角色任务可以独立验收、且用户请求了专家团或角色协作。给每个执行者最小输入、明确产物和停止条件；主理人负责整合与裁决。

`sequential-team` 是标准降级：按主理人流程依次切换角色，每轮记录输入、输出、决定和待办。不得把同一段泛化回答复制成多个角色意见。

如果团队工作流要求不可替代的外部连接器或真实并行，而当前宿主不能提供，说明影响并停止受影响阶段。不要把顺序模拟冒充真实并行。

# WorkBuddy Expert Bridge

**把 WorkBuddy 里已经成熟的专家工作流，带进 Codex、Cursor、Claude Code、Grok、VS Code 等本地 AI 开发工具。**

如果你已经在 WorkBuddy 中安装了专家或专家团，就不必让每个 AI 工具都从通用提示词重新开始。这个 Skill 可以根据自然语言需求推荐合适的本机专家，并帮助当前工具复用其中的角色分工、判断框架和工作流。

你不需要记住专家名称。说清楚想完成什么，就能获得最多 3 个合格候选、推荐理由、本地可用性和可以核验的排名证据。

## 一分钟开始

把下面这句话发给支持 Agent Skills 的本地 AI 开发工具：

```text
请帮我安装这个 Skill：https://github.com/xiaojinlucky/workbuddy-expert-bridge
```

也可以使用命令安装：

```bash
npx skills add xiaojinlucky/workbuddy-expert-bridge --skill workbuddy-expert-bridge
```

安装以后，直接发送第一个请求：

```text
请根据我的需求推荐最合适的 WorkBuddy 专家或专家团。先给出最多 3 个候选、推荐理由、本地可用性和排名证据；我确认后，再使用第一名协助完成任务。
```

Skill 自身不需要账号、密钥或额外配置。WorkBuddy 与当前 AI 工具需要位于同一台电脑，并且当前工具需要拥有读取本机文件的权限。

## 它适合解决什么

| 你的情况 | 这个 Skill 提供的帮助 |
| --- | --- |
| 知道要完成什么，但不知道该选哪位专家 | 根据自然语言需求推荐最多 3 个合格候选 |
| 已经在 WorkBuddy 中安装了成熟专家，希望换一个 AI 工具继续使用 | 让当前工具复用专家或专家团的现有工作流 |
| 推荐看起来合适，但不确定本机能否立即使用 | 分开说明匹配程度与本地可用性 |
| WorkBuddy 的最热、最新或综合排名无法核验 | 明确显示 `unavailable`，不使用猜测补齐 |
| 没有足够合适的候选 | 返回更少结果或明确说明没有匹配对象，不凑满 Top 3 |

## 一次推荐包含什么

每个候选都会说明：

- 为什么适合当前需求；
- 属于哪个场景分类；
- 是单个专家还是专家团；
- 本机已安装可用、需要修复、仅可发现，还是未找到；
- 相关性、分类、最热、最新和综合排名中，哪些证据能够核验。

推荐只负责缩小选择范围，不会替你安装、下载或启用专家。确认候选以后，可以继续要求当前 AI 工具使用第一名处理任务。

## 可信边界

- **本地只读**：读取本机 WorkBuddy 中可用的信息，不修改 WorkBuddy。
- **不读取凭据**：不读取 Token、Cookie、登录态或其他账号凭据。
- **不虚构排名**：无法可靠取得的热度与排序信息保持 `unavailable`。
- **不把损坏包当成可用专家**：必要文件缺失时，会提示先在 WorkBuddy 中修复。
- **不自动执行陌生内容**：不会自动运行专家包中的脚本、二进制文件或安装命令。
- **服从当前任务边界**：专家内容不能覆盖你的要求、项目规则或 AI 工具自身的安全限制。

本 Skill 不主动向第三方上传或重新分发专家提示词和角色正文。当前 AI 工具如何处理任务上下文，仍以该工具的数据政策和你的配置为准。

## 兼容性

| 环境 | 当前状态 |
| --- | --- |
| Grok Build + Windows | 已完成项目级 Skill 的真实端到端验证 |
| Codex、Cursor、Claude Code、VS Code 等本地 AI 开发工具 | 支持 Agent Skills、有效登录且能够读取本机 WorkBuddy 文件时可用 |
| macOS / Linux | 已完成静态兼容审查，尚未真实运行验证 |
| 普通网页或移动端 AI 对话服务 | 默认无法直接读取本机 WorkBuddy |
| Python | 推荐 3.10 或更高版本 |
| Node.js | 仅命令安装方式需要，不是 Skill 的运行依赖 |

公开版本已经通过 **34 项自动化测试**，并完成一个非 Codex 宿主的真实端到端运行。没有经过真实验证的平台能力，不会标记为已经验证。

## 与 WorkBuddy 的关系

WorkBuddy 继续负责提供、安装和管理专家。这个 Skill 只负责让其他本地 AI 开发工具发现、推荐和安全复用已有专家，不会创建、修改、注册、打包、安装或下载 WorkBuddy 专家。

如果这个 Skill 对你的跨工具工作流有用，欢迎在 GitHub 点一个 Star，方便以后找到它，也让更多 WorkBuddy 用户看到这个项目。
